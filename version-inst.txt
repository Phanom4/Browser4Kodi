**Browser4Kodi Helper**
Dieses Add-on ist eine erforderliche Komponente von Browser4Kodi. Es übernimmt die Skin-Verwaltung sowie die Bereinigung zugehöriger Erweiterungen.
Solange Browser4Kodi installiert ist, wird der Helper bei einer manuellen Deinstallation automatisch wiederhergestellt.
**Deinstallation**

1. Zuerst Browser4Kodi deinstallieren.
2. Anschließend Browser4Kodi Helper deinstallieren.


# ======================
# Version 1
# ======================
# Qellen
wget -O Browser4Kodi-addon.zip \
https://github.com/Phanom4/Browser4Kodi/releases/download/beta/Browser4Kodi-addon.zip
install in Kodi Addon aus Zip-Datei installieren

# ======================
# Version 4 linux
# ======================
# Bitte Beachten
# 50 Gb festplattenspeicher
# Download der Quellen: über 30 Minuten bei 100 mbits Telekom
# Kompilierung von CEF: über 40 Minuten bei 32 kerne 64 threads 64 gb Ram
# Kompilierung von Browser4Kodi: X Minuten bei 32 kerne 64 threads 64 gb Ram
# Betriebssystem Gentoo

# Qellen
wget -O Browser4Kodi-addon.zip \
https://github.com/Phanom4/Browser4Kodi/releases/download/beta/Browser4Kodi-addon.zip
unzip  Browser4Kodi-addon.zip
cd Browser4Kodi/k21_3_c150/
# 1. Neu beginnen
rm -rf build cef chromium depot_tools automate-git.py

git clone --branch 7871 --single-branch https://github.com/chromiumembedded/cef.git cef

wget https://raw.githubusercontent.com/chromiumembedded/cef/master/tools/automate/automate-git.py

# 2. Quellen herunterladen, noch nicht bauen
python3 automate-git.py \
  --download-dir="$(pwd)" \
  --branch=7871 \
  --no-build \
  --no-distrib \
  --no-chromium-history \
  --x64-build

# 3. Synchronisierung wiederholen und Ergebnis prüfen
cd chromium
../depot_tools/gclient sync --nohooks --no-history

if [ $? -ne 0 ]; then
    echo "FEHLER: Chromium-Synchronisierung unvollständig"
else
    echo "Chromium-Synchronisierung erfolgreich"
fi

cd ..


GN_DEFINES="is_official_build=true use_sysroot=true symbol_level=0 is_cfi=false use_thin_lto=false chrome_pgo_phase=0" \
python3 automate-git.py \
  --download-dir="$(pwd)" \
  --branch=7871 \
  --no-update \
  --force-build \
  --no-debug-build \
  --build-target=cefsimple \
  --x64-build \
  --no-chromium-history

#Browser4Kodi
cmake -S . -B build && cmake --build build -j 64
